Fold Worlds wallpapers

Every world, painted for a phone screen at every two hours of the day. The pictures match the time, so a Shortcut can swap your wallpaper as the day goes on.

Open the living worlds: tap Share, then Add to Home Screen, to keep them as an app.

Worlds, right now

Wallpaper that follows the time of day

  1. Open Shortcuts, tap +, name it World Wallpaper.
  2. Add Format Date: Date = Current Date, Format = Custom, Format String = H.
  3. Add Calculate: Formatted Date ÷ 2.
  4. Add Round Number: Mode = Always Round Down.
  5. Add Calculate: Rounded Number × 2.
  6. Add URL: and put the last Calculation Result where it says HOUR. Change lava to any world name below.
  7. Add Get Contents of URL, then Set Wallpaper Photo (choose Lock Screen, Home Screen or both; turn off Show Preview).
  8. Go to Automation › + › Time of Day. Make one for each time you want a change (say 6 am, 9 am, noon, 5 pm, 7 pm, 10 pm), choose Run Immediately, and run World Wallpaper.

Moving lock screen (Live Photo)

Each world also has a short looping video (the Loop button). iPhone only moves Live Photos on the lock screen, so turn the video into one first:

  1. Open the loop and save it to Photos (Share › Save Video).
  2. Convert it with a free app such as intoLive (choose Live Photo, no repeat needed).
  3. Settings › Wallpaper › Add New › Photos, pick the Live Photo, and tap the play icon so it moves.
